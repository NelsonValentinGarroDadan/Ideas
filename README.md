# 💡 **Mural de Ideas** 🖌️

Un mural interactivo donde los usuarios pueden agregar ideas, verlas reflejadas en un mural que cambia con cada recarga, y almacenarlas de manera anónima o con nombre en **MongoDB**. ¡Perfecto para compartir pensamientos creativos y generar nuevas ideas!

### 🔗 **[Ver el proyecto en vivo aquí](https://ideas-633x.onrender.com/ideas)**

---

## 🚀 **Características principales**
- 🌱 Cada vez que recargas el mural, el contenido cambia con nuevas ideas.
- ✍️ Permite agregar ideas de forma anónima o con el nombre del autor.
- 🎨 Las ideas se muestran en tarjetas con colores aleatorios para dar un toque visual único.
- 💾 Las ideas se almacenan en **MongoDB** usando **Mongoose**.
- 💡 En el futuro, se implementará una gestión de donaciones para apoyar el proyecto.

## 🛠️ **Cómo usar el proyecto**

### 1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```
2. Navega al directorio del proyecto:
```bash
cd tu-repositorio
```
3. Instala las dependencias:
```bash
npm install
```
4. Compila el proyecto:
```bash
npm run build
```
5. Inicia el servidor:
```bash
npm start
```
6. Abre tu navegador y accede a la URL:
```bash
http://localhost:puerto/ideas (Reemplaza puerto con el puerto donde esté corriendo tu servidor)
```

## 🎨 **Uso del mural**
Agregar una nueva idea: En la página principal, utiliza el formulario para agregar una idea. Puedes hacerlo de forma anónima o agregando tu nombre.
Ver ideas: Las ideas se muestran en tarjetas coloridas con colores aleatorios. ¡Cada recarga trae algo nuevo!
Próximos pasos: Se implementará una opción para gestionar donaciones para apoyar el desarrollo de la aplicación.
